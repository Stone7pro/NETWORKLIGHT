# NETWORKLIGHT
NetworkLight - host availability monitor for Windows: checks via ICMP (ping) or TCP, shows latency and packet loss in a table and graph. Various sounds indicate losses, failures and restoration of communication, and a colored tray icon shows the network status even when the window is minimized. There are email notifications and TXT import/export.

- **Node monitoring.** Check by IP address or name via ICMP (ping) or TCP. For each node, you can set the polling frequency and alarm conditions.

- **Statistics and graph** The table shows the number of surveys, responses and losses, as well as the minimum, average and maximum response time. The graph of the selected node shows the latency and marks the gaps.

- **Color indication.** Green - the node is responding, yellow - there are losses, red - there is no connection. Color highlighting of cells helps you quickly notice losses and latency changes.

- **Sound notifications.** Different signals for packet loss, connection failure and connection restoration help you understand what happened by ear. The sound can be turned off for an individual node or for all at once.

-  **Notifications by email.** Emails tell you which node lost or restored communication and when it happened. The restoration letter also indicates the duration of the downtime.

- **The overall “pulse” of the network.** The animation changes color and rhythm depending on the state of the nodes. When the window is hidden, the overall picture is shown by a two-color indicator in the system tray.

- **List management.** Nodes can be loaded from a text file and uploaded back, each one can be given a clear name and a detailed comment, and important nodes can be pinned at the top of the list.

- **Dock the window.** The Dock option keeps the monitor on the screen when you press **Win+D**.
