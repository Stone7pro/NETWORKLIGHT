# NETWORKLIGHT
NetworkLight - host availability monitor for Windows: checks via ICMP (ping) or TCP, shows latency and packet loss in a table and graph. Various sounds indicate losses, failures and restoration of communication, and a colored tray icon shows the network status even when the window is minimized. There are email notifications and TXT import/export.

NetworkLight — монитор доступности хоста для Windows: проверяет через ICMP (ping) или TCP, показывает задержку и потерю пакетов в таблице и графике. Различные звуки сигнализируют о потерях, сбоях и восстановлении связи, а цветной значок в трее показывает состояние сети даже при свернутом окне. Есть уведомления по электронной почте и импорт/экспорт TXT.

**Node monitoring.** Check by IP address or name via ICMP (ping) or TCP. For each node, you can set the polling frequency and alarm conditions.
**Statistics and graph** The table shows the number of surveys, responses and losses, as well as the minimum, average and maximum response time. The graph of the selected node shows the latency and marks the gaps.
**Color indication.** Green - the node is responding, yellow - there are losses, red - there is no connection. Color highlighting of cells helps you quickly notice losses and latency changes.
**Sound notifications.** Different signals for packet loss, connection failure and connection restoration help you understand what happened by ear. The sound can be turned off for an individual node or for all at once.
**Notifications by email.** Emails tell you which node lost or restored communication and when it happened. The restoration letter also indicates the duration of the downtime.
**The overall “pulse” of the network.** The animation changes color and rhythm depending on the state of the nodes. When the window is hidden, the overall picture is shown by a two-color indicator in the system tray.
**List management.** Nodes can be loaded from a text file and uploaded back, each one can be given a clear name and a detailed comment, and important nodes can be pinned at the top of the list.
**Dock the window.** The Dock option keeps the monitor on the screen when you press **Win+D**.

**NetworkLight** — монитор сети для Windows. Он помогает заметить потерю связи и её восстановление, даже когда вы не смотрите на экран: программа подаёт звуковые сигналы и отправляет уведомления на почту.

**Мониторинг узлов.** Проверка по IP-адресу или имени через ICMP (ping) или TCP. Для каждого узла можно задать частоту опроса и условия тревоги.
**Статистика и график.** Таблица показывает число опросов, ответов и потерь, а также минимальное, среднее и максимальное время ответа. График выбранного узла показывает задержку и отмечает пропуски.
**Цветовая индикация.** Зелёный — узел отвечает, жёлтый — есть потери, красный — связи нет. Цветовое выделение ячеек помогает быстро заметить потери и изменения задержки.
**Звуковые уведомления.** Разные сигналы для потери пакетов, падения и восстановления связи помогают понять, что случилось, на слух. Звук можно отключить для отдельного узла или сразу для всех.
**Уведомления на почту.** Письма сообщают, какой узел потерял или восстановил связь и когда это произошло. В письме о восстановлении также указана длительность простоя.
**Общий «пульс» сети.** Анимация меняет цвет и ритм в зависимости от состояния узлов. Когда окно скрыто, общую картину показывает двухцветный индикатор в системном трее.
- **Управление списком.** Узлы можно загрузить из текстового файла и выгрузить обратно, дать каждому понятное название и подробный комментарий, а важные узлы закрепить вверху списка.
- **Закрепление окна.** Опция «Закрепить» оставляет монитор на экране при нажатии **Win+D**.
